# 키픽 스토리 시안 — 일러스트 교체 안내 (혜민님용)

주소: `/story-draft` (실제 메인 `/`은 그대로예요 · 검색에 안 나오는 시안 주소)
글꼴 비교: `/fonts-draft`

지금 화면의 그림은 모두 **임시 도형**(코드로 그린 구름·언덕·사진 카드·앨범·집)이에요.
일러스트레이터로 그린 조각을 넣으면 **그 조각만** 진짜 그림으로 바뀌어요. 코드는 건드리지 않고 파일 한 줄만 바꿔요.

## 한눈에 보는 순서

1. 일러스트레이터에서 조각 하나씩 **SVG**(또는 PNG)로 내보내요 → 아래 "내보내기 규칙" 참고
2. 파일 이름을 아래 표의 **레이어 이름**과 똑같이 해서 `public/story/layers/` 폴더에 넣어요
   (예: `public/story/layers/cloud-1.svg`)
3. `app/story-draft/layers.ts` 에서 그 레이어 줄의 `src: null` 을 `src: "/story/layers/cloud-1.svg"` 로 바꿔요
4. 새로 고침하면 그 조각만 바뀌어 있어요. 위치·크기가 어색하면 같은 줄의 `cx, cy, w` 숫자만 고치면 돼요

## 내보내기 규칙 (일러스트레이터)

- **조각마다 따로 파일 1개.** 배경(흰색 등) 없이 **투명 배경**
- 아트보드를 **그림 크기에 딱 맞게**(여백 없이) 잘라서 내보내기 — "콘텐츠에 맞게 아트보드 자르기" 또는 `개체 → 아트보드 → 선택 영역에 맞춤`
- **SVG 추천**(깨끗하게 커지고 용량이 작아요): `파일 → 내보내기 → 내보내기 형식 → SVG`, 스타일 "프레젠테이션 속성", 글자는 **윤곽선으로 만들기**, 이미지는 "링크" 말고 **포함**
- 사진 질감이 있어 SVG가 무거워지면 **PNG**: 가로 기준 **실제 크기의 2배**(아래 표의 "권장 PNG 폭"), 배경 투명, 용량은 한 장 200KB 이하 권장
- 색 모드는 RGB. 파일 이름은 **영문 소문자·숫자·하이픈**만 (한글·공백 금지)
- 가로 방향으로 화면 끝까지 꽉 채우는 조각(언덕)은 **가로로 넉넉히 긴 모양**(권장 3000×900 px 안팎)으로 그리고, 양 끝이 화면 밖으로 이어지는 느낌으로 만들면 어떤 화면 폭에서도 자연스러워요
- 바꾼 조각의 **가로:세로 비율**이 표의 ar와 다르면 `layers.ts`의 `ar`(가로÷세로)를 실제 비율로 고쳐 주세요 (예: 400×200 px 이면 `ar: 2`)

## 레이어 이름 표

`위치`의 "화면 전체"는 가로로 꽉 찬 배경 영역, "그림 영역"은 가운데 정사각형 영역이에요.
`속도`는 스크롤할 때 움직이는 정도(1 = 보통, 작을수록 멀리 있는 듯 느리게, 클수록 가까이 있는 듯 빠르게).

### 장면 2 · 앨범으로 만들어져요 (`Scene2Album.tsx`)

앨범은 **세 조각**으로 나뉘어 있어요. 표지가 넘어가며 열리고, 표지의 "뒷면"이 왼쪽 속지가 돼요.

| 레이어 이름 | 무엇 | 비율(가로:세로) | 권장 PNG 폭 |
|---|---|---|---|
| `s2-cover` | 앨범 **앞표지**(닫혀 있을 때 보이는 면) | 3:4 | 600 |
| `s2-page-left` | **왼쪽 속지**(표지를 열면 보이는 안쪽 면) | 3:4 (표지와 같은 크기) | 600 |
| `s2-page-right` | **오른쪽 속지**(펼쳤을 때 오른쪽) | 3:4 (표지와 같은 크기) | 600 |
| `s2-card-1` ~ `s2-card-6` | 날아가는 사진 카드(6장 모두 같은 크기, 사진 내용만 달라도 돼요) | 4:5 | 300 |
| `s2-shadow` | 앨범 아래 그림자 | 8:1 | 1200 |
| `s2-spark-1` ~ `s2-spark-3` | 반짝이 | 1:1 | 80 |
| `s2-cloud-1`, `s2-cloud-2` | 구름 | 2:1 | 700 |

- 표지·속지는 **세 장의 크기를 똑같이** 맞춰서 내보내 주세요(앨범이 열릴 때 딱 맞게 겹쳐요).
- 사진 카드는 속지에서 **조금 작아져서**(가로 15%) 앉아요. 속지 위에 앉는 모습이 예쁘도록 가장자리에 흰 테두리·그림자가 있으면 좋아요.

#### 길 그림 바꾸기 (조금 특별해요)

앨범이 지나가는 길은 `layers.ts` 맨 아래 `ROUTE.d` 라는 **한 줄 선의 모양**이에요.
`s3-path` 그림을 새로 그리면, 그림 속 길의 **가운데 선**이 이 선과 겹쳐야 앨범이 길 위를 걸어가요.

- 쉬운 방법: 길 그림을 **정사각형 아트보드**에 그리고, 길의 가운데 선을 별도 선(스트로크)으로 하나 더 그려서 "패스 데이터(d)"를 저(Claude)에게 알려 주세요. 제가 `ROUTE.d`를 맞춰 드려요.
- 길을 그림에서 크게 바꾸지 않고 색·질감만 입힐 때는 지금 선 그대로 써요.

## 화면에서 바뀌지 않는 것(코드가 해줘요)

- 위아래 흔들림·반짝임·폴짝 같은 **가만히 있을 때 움직임**, 스크롤에 따른 **시차(멀고 가까움)**, 장면 2의 **카드가 날아가 앨범이 열리고 닫히는 순서**, 장면 3의 **길 따라 이동**은 모두 코드가 해요. 그림은 "정지 그림"만 주시면 돼요.
- 하늘·바닥 **배경색 그라데이션**은 일러스트가 아니라 코드(`story.css`의 `--st-bg`)예요. 색을 바꾸고 싶으면 말씀해 주세요.
- "동작 줄이기" 설정을 켠 기기에서는 움직임 없이 **완성된 모습**으로 보여줘요(앨범이 펼쳐지고 사진이 다 채워진 모습 / 앨범이 집 앞에 도착한 모습).

## 제목 글꼴 바꾸기

`app/story-draft/fonts.ts` 에서 `Jua` 를 다른 후보로 바꾸면 돼요. 후보는 `/fonts-draft` 에서 비교할 수 있어요.

## 파일 지도

| 파일 | 역할 |
|---|---|
| `layers.ts` | **레이어 목록표**(이름·그림 파일·위치·크기·속도·움직임) — 여기만 고치면 돼요 |
| `placeholders.tsx` | 임시 도형 그림(진짜 그림이 다 들어오면 지워도 돼요) |
| `Scene1Hero.tsx`, `Scene2Album.tsx`, `Scene3Home.tsx` | 장면별 구성과 스크롤 연동(장면당 파일 하나) |
| `SceneText.tsx` | 제목(글자가 톡톡 튀어나옴)·부제·버튼 |
| `scrollBus.ts` | 스크롤 감시자(1개) |
| `story.css` | 모양·움직임 스타일 |
