# 키픽 스토리 시안 — 일러스트 안내 (혜민님용)

주소: `/story-draft` (실제 메인 `/`은 그대로예요 · 검색에 안 나오는 시안 주소)
글꼴 비교: `/fonts-draft`

컨셉은 **"추억이 모여 나만의 우주가 되는 곳"** 이에요. 파랑·보라 우주 + 크림색 별, 제목은 **차이 활짝체** 크림색에 강조 낱말만 분홍색이에요(테두리·그림자 없음).

| 장면 | 배경 그림 | 무엇이 움직이나요 |
|---|---|---|
| 1 · 사진 고르기 | `bg-cobalt-space` | 달·행성·구름·별이 둥실, 사진 카드 3장과 카메라가 위아래로 떠다녀요. 스크롤하면 멀리 있는 것은 느리게, 가까운 것은 빠르게(시차) |
| 2 · 사진이 우리 물건이 돼요 | `bg-purple-space` | 닫힌 앨범이 펼쳐지고, 사진 3장이 **별빛 궤도(점선 타원)** 를 따라 돌다가 속지에 앉아요 → 앨범이 닫히고 → **액자 → 머그컵 → 에코백 → 캘린더**가 하나씩 차례로 나와요(앨범이 제일 크고 액자·굿즈 순). 아래 안내 글이 “앨범 → 액자 → …”로 이어 붙어요 |
| 3 · 집에 도착! | `bg-delivery-road` | 별표 택배 상자(=완성된 상품)가 **배송 길**을 따라 작은 집까지 가요 → 하트가 톡, 포토북을 든 소녀가 나타나요 |

스크롤을 멈추면 그 자리에서 멈추고, 올리면 거꾸로 되감겨요. “동작 줄이기”를 켠 기기에서는 움직임 없이 완성된 모습으로 보여요.

## 1. 그림 바꾸기 (제일 중요)

원본 PNG(큰 파일)는 **프로젝트에 넣지 않아요.** 대신 스크립트가 알아서 작게 줄여서(WebP) `public/story/layers/` 에 넣어 줘요.

1. 일러스트 PNG들을 한 폴더에 모아요. (파일 이름 **맨 끝의 번호**가 중요해요: `...-14.png` 처럼. 앞의 한글 이름은 뭐든 괜찮아요)
2. 터미널에서 프로젝트 폴더에서 이 한 줄을 실행해요.

```
node scripts/optimize-story-art.mjs "/Users/내이름/Desktop/홈페이지 일러스트소스"
```

3. 새로 고침하면 끝! 한두 장만 바꿨다면 번호만 골라서 다시 만들 수 있어요: `... --only 14,20`
4. `node scripts/optimize-story-art.mjs --list` 를 치면 번호와 이름표를 볼 수 있어요.

스크립트가 해 주는 일: ① 번호로 파일 찾기 ② 둘레의 투명한 빈 곳 잘라내기 ③ 화면에서 쓰는 크기의 약 2배로 줄이기(배경 1600px, 물건 140~760px) ④ 거의 안 보이는 투명 얼룩 정리 ⑤ WebP로 저장(장당 4~70KB) ⑥ 그림 크기를 `art-manifest.json` 에 기록(+배경은 흐릿한 미리보기 색도 기록, 큰 그림이 오기 전에 화면이 비어 보이지 않게).
→ 30장 42MB가 합쳐서 약 0.9MB가 됐어요.

## 2. 장면에서 조각 바꾸기 · 더하기

- **같은 조각의 그림만 교체**: 같은 번호로 끝나는 PNG를 폴더에 넣고 위 명령을 다시 실행해요. 코드는 안 건드려도 돼요.
- **다른 조각으로 바꾸기**: `layers.ts` 에서 그 줄의 `art: "star-pink"` 를 `art: "star-cream"` 처럼 다른 조각 이름으로 고쳐요.
- **위치·크기·속도 조절**: `layers.ts` 같은 줄의 숫자를 고쳐요 — `cx, cy`(가운데 점 %) · `w`(가로 크기 %) · `depth`(스크롤 속도) · `z`(겹침 순서) · `idle`(둥실/위아래/반짝). 숫자 읽는 법은 `layers.ts` 맨 위에 적어 두었어요.
- **글자 자리를 가리는 장식**은 `land`(가로 화면용 다른 위치)로 옮길 수 있어요. 예: `land: { cx: 48, cy: 10 }`
- **완전히 새 조각 추가**: ① 새 PNG 번호를 정해 `scripts/optimize-story-art.mjs` 위쪽 표에 한 줄 추가(번호·영문 이름·가로 크기) ② 스크립트 실행 ③ `layers.ts` 에 한 줄 추가 ④ 해당 장면 파일(`Scene1Hero.tsx` 등)의 목록에 이름 추가.
- 파일 이름은 **영문 소문자·숫자·하이픈**만 써요(한글·공백 금지).

## 3. 배경은 어떻게 맞췄나요 (알아 두면 좋은 점)

- 배경 3장은 가로로 긴 3:2 그림이에요. **이어 붙이는(타일) 용도로는 쓸 수 없어요**(좌우가 이어지지 않아요). 그래서 화면에 꽉 차게(cover) 깔아요.
- 폰 세로 화면(좁고 길쭉)에서는 가로 그림의 가운데만 보여요. 장면 1·2는 가운데 비워 둔 그림이라 문제없어요. **장면 3(길)** 은 길 전체가 보이도록 그림을 아래쪽에 크게 깔고, 상자가 가는 동안 **화면이 상자를 따라 옆으로 밀려요**(카메라 효과). 그림 위쪽은 우주 바탕색으로 부드럽게 이어져요.
- 글자 뒤에는 어두운 번짐(scrim)·그림자를 깔지 않아요. 70차에 넣었던 `.st-text::before`(남색 radial-gradient)가 "넓은 남색 얼룩"의 원인이라 71차에 지웠어요.
- 첫 화면 배경(`bg-cobalt-space`)은 가장 먼저 받고, 받는 동안은 대표 색 + 아주 작은 흐린 그림이 보여요. 아래 장면 그림은 스크롤이 가까워질 때 받아요.

### 길 선 맞추기 (장면 3)

상자가 가는 길은 `layers.ts` 맨 아래 `ROUTE.d` 예요. 길 그림(`bg-delivery-road`)을 가로 150 × 세로 100 칸으로 보고, **크림색 길의 가운데 선**을 따라 점을 찍어 곡선으로 이은 거예요. 방법: 그림에서 크림색(밝은 노란 베이지)만 골라 가로줄마다 길의 가운데 위치를 읽고 → 그 점들에 곡선을 맞추고 → 그림 위에 겹쳐 그려서 길 안에 들어오는지 눈으로 확인했어요. 길 그림을 새로 그리면 이 선도 다시 맞춰야 해요(저한테 말씀해 주세요). 집·소녀·하트의 위치도 같은 그림 기준(% 단위)이에요.

## 4. 파일 지도

| 파일 | 역할 |
|---|---|
| `layers.ts` | **레이어 목록표**(이름·그림·위치·크기·속도·움직임) + 장면 3 길(ROUTE) |
| `art-manifest.json` | 그림별 가로·세로·용량(스크립트가 자동으로 써요, 직접 고치지 않아요) |
| `Layer.tsx` | 그림 한 장을 화면에 놓는 부품(가로·세로 크기 미리 지정, 아래 장면은 lazy 로딩) |
| `Scene1Hero.tsx`, `Scene2Album.tsx`, `Scene3Home.tsx` | 장면별 구성과 스크롤 연동 |
| `SceneText.tsx` | 제목(통짜 한 문장, 들어올 때 전체가 한 번 살짝 떠오름, 강조 낱말 분홍)·설명(뜻 단위 두 줄)·버튼 |
| `fonts.ts` | 첫 화면에서 미리 받아 둘 글꼴 파일 목록 |
| `scrollBus.ts` | 스크롤 감시자(1개) |
| `story.css` | 모양·색·움직임 스타일(`--st-pink` 등 색은 맨 위에) |
| `../../scripts/optimize-story-art.mjs` | PNG → WebP 최적화 스크립트 |

## 5. 글꼴 (70차)

- **제목(큰 글씨)만 차이 활짝체 Bold** — `public/fonts/ChaiHwaljjak-Bold.otf` (선언은 `app/globals.css` 의 `ChaiHwaljjak`, 굿즈·편집기와 같은 파일). 시안에서는 700만 받아요.
- **그 밖의 글(설명·버튼·작은 글씨)은 Pretendard 400·700** — `public/fonts/story/Pretendard-*-ksx1001.woff2` (원본 `public/fonts/Pretendard-*.ttf`(약 2.7MB)에서 자주 쓰는 한글 2350자+영문·숫자만 골라 담은 약 170KB 파일. Pretendard는 SIL OFL 라이선스).
- 글꼴이 오기 전에는 `size-adjust`로 폭을 맞춘 기기 기본 글꼴이 잠깐 보여서 글자 위치가 덜 출렁여요. 선언은 `story.css` 맨 위.
- 주의: 차이 활짝체 파일의 이름표(저작권 문구)는 “All rights reserved”이고 라이선스 문구가 없어요. 웹 임베딩 허용 여부는 배포처(차이커뮤니케이션/산돌) 확인이 필요해요.

## 6. 글자·버튼·장면 연결 규칙

- 제목에는 text-shadow·테두리·겹친 글자를 쓰지 않아요. 글자 뒤에는 어떤 어두운 번짐도 깔지 않아요(71차).
- 진짜 눌러야 하는 것은 분홍 납작 버튼(`.st-cta`)뿐이에요. 소개 글·단계 이름·진행 안내는 테두리 없는 일반 글씨예요.
- 장면 사이는 크고 완만한 곡선 하나(`.st-edge`, 위 장면 아래색이 다음 장면으로 살짝 내려와요)로 이어요. 작은 반원·물결 반복은 쓰지 않아요(71차).
- 구름 그림 2장(`cloud-cobalt`, `cloud-lavender`)은 배경 그림에 이미 구름이 있어서 화면에서는 안 써요(예비).
- 71차 글자 규칙: 제목 폰 34~42px · PC 56~72px(굵기 700), 설명 폰 16~18px · PC 18~20px(줄간격 1.6), 제목→설명 22px · 설명→버튼 30px, 버튼 높이 폰 50px · PC 54px.
- PC·태블릿 가로(높이 521px 이상)는 글자 가운데 정렬 + 그림 덩어리 아래 가운데, 폰 가로(높이 520px 이하)는 왼쪽 글자/오른쪽 그림. 가운데 정렬 배치에서만 쓰는 장식 위치는 layers.ts 의 `wide` 예요.
- 제목에는 글자별 효과·스크롤 연동 효과가 없어요. 장면 2·3 제목은 장면에 들어올 때 제목 전체가 14px 떠오르며 나타나요(한 번).
